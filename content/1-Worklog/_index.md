Over the internship at First Cloud AI Journey (from 14/09/2026), I worked through the program week by week. I started with AWS fundamentals, then built a serverless e-commerce project with an AI chatbot, and moved on to AI/ML services, DevOps, security, and containers.

**Week 1:** [Getting familiar with AWS: account setup, AWS Budgets, Support, and IAM](1.1-week1/)

**Week 2:** [AWS networking (VPC), EC2, Cloud9, S3 + CloudFront static website, and RDS MySQL](1.2-week2/)

**Week 3:** [WordPress/WooCommerce on Lightsail, SSL, Route 53, S3 + CloudFront media offload, and draw.io](1.3-week3/)

**Week 4:** [Serverless e-commerce: Cognito, React on S3 + CloudFront, DynamoDB, Lambda, API Gateway, SNS/SQS/EventBridge](1.4-week4/)

**Week 5:** [Private VPC, OpenSearch, DynamoDB Streams sync, AI chatbot with Lambda + Gemini API, and WebSocket API](1.5-week5/)

**Week 6:** [Amazon Bedrock, Bedrock AgentCore, SageMaker AI, AWS Continuum, and AWS RAM](1.6-week6/)

**Week 7:** [Terraform, CI/CD with GitHub Actions, Kiro Crew, and ETL with Glue + Athena](1.7-week7/)

**Week 8:** [Bedrock Evaluation for RAG, CloudTrail, GuardDuty, Amazon Q Business, and IAM Access Analyzer](1.8-week8/)

**Week 9:** [Bedrock Guardrails, IoT Greengrass, Lambda web functions, ALB, and Amazon ECS](1.9-week9/)

**Week 10:** [Amazon Rekognition + Athena, Textract, Comprehend, Secrets Manager & KMS, and Step Functions](1.10-week10/)

**Week 11:** [End-to-end Workshop deployment & testing (Next.js SSR, EventBridge/SQS, RAG Chatbot), security hardening, and cleanup](1.11-week11/)

**Week 12:** [AWS X-Ray, Well-Architected Framework, Pricing Calculator, Internship Report on GitHub Pages, and final demo](1.12-week12/)
